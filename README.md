
#  Криптосистема: DES через RSA с защитой ЭЦП EGSA

##  Описание

Данный проект реализует защищённую криптографическую систему из двух микросервисов:

- **`client-service`** — отправитель сообщения.
- **`server-service`** — получатель, проверяющий подлинность и расшифровывающий данные.


### На стороне клиента:

1. Генерация DES-ключа.
2. Шифрование текста с помощью DES.
3. Шифрование DES-ключа с помощью RSA.
4. Подпись зашифрованного ключа алгоритмом EGSA.
5. Отправка DTO (`EncryptedMessageDTO`) на сервер.

### На стороне сервера:

1. Проверка подписи EGSA.
2. Расшифровка DES-ключа с помощью RSA.
3. Расшифровка текста с помощью DES.
4. Возврат расшифрованного текста.

## Запуск проекта

1. Запустить `server-service` (порт `8081`).
2. Запустить `client-service` (порт `8080`).
3. Выполнить GET-запрос http://localhost:8081/public/keys
   Result:
```json

  "rsaE": "65537",
  "egsaY": "30684795920802069500051356260198440101264854386105572545881622215267688261804",
  "egsaX": "26228086287795517822649658403103517663657060956846979667485873943851145942602",

  "egsaP": "87383691310612216788490346876972044006808831757164117424943652789673705295799"
```

4. Отправить POST-запрос на `http://localhost:8080/encrypt`.

## Проверка корректности

- Ошибочная подпись EGSA → `Invalid EGSA signature`.
- Некорректный зашифрованный ключ → ошибка при расшифровке.
- Корректная цепочка → исходный текст возвращается.
